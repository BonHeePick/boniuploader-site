개인정보처리방침

최종 업데이트: 2026년 9월 5일

Uploader는 사용자가 승인한 Google 계정의 YouTube 채널에 동영상을 업로드하고 관련 작업을 수행하기 위한 개인용 애플리케이션입니다.

1. Google 사용자 데이터 접근

Uploader는 Google OAuth를 통해 사용자가 명시적으로 승인한 범위 내에서만 Google 및 YouTube 데이터에 접근합니다. 여기에는 YouTube 채널에 동영상을 업로드하거나 업로드 작업을 수행하는 데 필요한 권한이 포함될 수 있습니다.

2. 데이터 사용 목적

Google 사용자 데이터는 사용자가 요청한 YouTube 업로드 및 관련 기능을 제공하기 위한 목적으로만 사용됩니다. 광고, 판매, 프로파일링 또는 그 밖의 무관한 목적으로 사용하지 않습니다.

3. 인증 정보 보관

애플리케이션의 지속적인 인증을 위해 OAuth 액세스 토큰 또는 갱신 토큰이 사용자의 로컬 환경 또는 애플리케이션 실행 환경에 저장될 수 있습니다. 해당 정보는 YouTube API 인증 및 사용자가 요청한 기능 수행을 위해서만 사용됩니다.

4. 제3자 제공

Uploader는 Google 사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다. 다만 법령상 요구가 있는 경우에는 예외가 될 수 있습니다.

5. 데이터 보호

Uploader는 인증 정보와 사용자 데이터를 불필요하게 공개하지 않도록 합리적인 보호조치를 적용합니다.

6. Google API Services 정책 준수

Uploader의 Google API 사용 및 Google 사용자 데이터의 처리에는 Google API Services User Data Policy가 적용되며, 관련 Limited Use 요구사항을 준수합니다.

7. 접근 권한 철회

사용자는 언제든지 Google 계정의 보안 설정에서 Uploader에 부여한 접근 권한을 철회할 수 있습니다.

8. 문의

개인정보 또는 애플리케이션 관련 문의는 OAuth 동의 화면에 등록된 개발자 연락처 이메일을 통해 문의할 수 있습니다.
